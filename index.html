Code/Lab Design System

Colors, type, and materials for CodeLab Davis — restructured from a palette tagged directly in Figma (@claude), generated as OKLCH scales, and validated to WCAG AA.

7 color scales 11 steps per scale 4.5:1 min contrast 3 type families

Colors

Six brand scales tagged in Figma, plus a neutral scale for text and surfaces — 11 steps each, generated in OKLCH. Hover a square for its value.

Typography

Three families, three jobs: Poppins for display, Inter for interface and body, JetBrains Mono for code and tokens.

Pairing note Poppins and Inter both classify as sans — rather than swap either, a third technical face (JetBrains Mono) was added for code and labels only, never prose.

Accessibility

Every pairing checked against WCAG 2.x. One failed and was corrected before shipping as a token.

PairingForegroundBackgroundRatioVerdict
Correction on record White text on red-500 (#FF2B00) measures 3.75:1 — fails the 4.5:1 text threshold. Solid buttons reference red-600 instead (5.62:1); red-500 stays reserved for accents and large fills.

Tokens

Naming architecture
